# Следующий релиз

Target release: `1.0.8`.

Проверенные изменения:

- [x] Новый раздел Graphs в menu bar popover.
- [x] Process History для CPU, Memory и Energy с интервалами 30 минут/4 часа, фильтром мелких процессов, linear/log шкалой и hover-информацией.
- [x] Интерактивная Thermal Surface с доступными температурными зонами, компонентным слоем, fan airflow и доступной power/display телеметрией.
- [x] Consumer-aware cadence, bounded history, приостановка скрытой thermal-анимации и проверка нагрузки Release-сборки.
- [x] Визуальные снимки Process History и Thermal Surface для GitHub Release.

Публикуемый текст хранится в `MacCleaner/ReleaseNotes.md` по правилам [[GitHubAndReleases]]. После публикации `v1.0.8` очередь необходимо очистить и переключить на следующий patch.
