# Следующий релиз

Target release: `1.0.9`.

Проверенные изменения:

- [x] Отдельная вкладка Fan control в menu bar popover с независимым управлением каналами.
- [x] Режимы macOS Auto, выбранный RPM и десятисекундный Maximum с автоматическим возвратом в Auto.
- [x] Живая история температур и события запуска, остановки и изменения оборотов вентиляторов.
- [x] Локальная установка helper после системного подтверждения администратора с привязкой к конкретной подписи сборки.
- [x] Исправления видимости активной кнопки Thermal Surface, переключения графиков и фоновых обновлений.

Публикуемый текст хранится в `MacCleaner/ReleaseNotes.md` по правилам [[GitHubAndReleases]]. После публикации `v1.0.9` очередь необходимо очистить и переключить на следующий patch.
